## 2. Inviolable Cross-Skill Primary Standards

Every Primary Skill in this ecosystem strictly enforces the following immutable architectural rules:

1. **Strict Zero Emoji Policy**:
   - Zero emojis across all markdown documentation, UI copy, code comments, database DDL, and API responses.
2. **Google Material Symbols Outlined Exclusively**:
   - Standard optical weight 500 (`font-variation-settings: 'FILL' 0, 'wght' 500, 'GRAD' 0, 'opsz' 24`).
3. **Liquid Glass Design DNA**:
   - Frosted white canvas (`bg-white/80 backdrop-blur-xl border border-white/60`).
   - 360-degree specular highlights (`border-t border-white/95`).
   - Hard tactile offset shadows (`shadow-[0_8px_0_0_rgba(15,23,42,0.06)]`).
4. **Neon PostgreSQL Multi-Tenant Row-Level Security (RLS)**:
   - All tenant queries constrained by `branch_id = current_setting('app.current_branch_id')`.
5. **Synchronous-to-Asynchronous Kafka Architecture**:
   - Heavy batch generation (payroll, invoicing, mass marksheets, bulk admit cards, SMS/email bursts) buffered through Kafka topics to Spring Boot 3 virtual thread workers.

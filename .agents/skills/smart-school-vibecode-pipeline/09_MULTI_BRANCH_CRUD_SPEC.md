# Multi Branch Module — Complete Functional & Governance Specification
## Universal Enterprise School Management System (Brand-Agnostic Blueprint)

---

### Executive Overview & Multi-Campus Architecture

The **Multi Branch** module is the central **Cross-Campus Federation & Multi-Tenant Control Hub** of the platform. It provides the Super Admin with sovereign visibility across physical campuses, subsidiary school branches, and distributed institutions while maintaining strict cryptographic and database tenant isolation.

It implements three primary multi-campus UI layout paradigms:
1. **Stacked Multi-Table Institutional Audit Dashboard**:
   - Master executive overview displaying 5 stacked cross-branch summary tables covering Tuition Fees, Transportation Receivables, Student Admissions (Offline vs. Online), Library Media Circulation, and Alumni tracking, with a top print utility.
   - Applied to: `Overview`.
2. **Cross-Campus Multi-Branch Report Directory Hub**:
   - 3-column categorical report launcher linking to cross-branch financial collections, payroll expenditures, income, expenses, and security user logs.
   - Applied to: `Report`.
3. **Branch Federation & Instance URL Router Console**:
   - High-capacity data grid managing branch URLs and routing endpoints for distributed multi-branch deployments with `+ Add New` branch registration.
   - Applied to: `Setting`.

### Slug 01: Overview (`/multi-branch/overview`)
*Layout: Stacked Multi-Table Cross-Branch Comparison Dashboard*

#### 1. Top Header & Action
- Title: `Overview`
- Top-Right Action: `Print` button (launches formatted cross-campus executive report).

#### 2. The 5 Stacked Cross-Branch Comparison Tables

##### Table 1: Fees Details (Tuition & Session Billing)
- Columns:
  1. `Branch`: Name of campus (e.g. `Home Branch`, `Branch 2`, `Branch 3`)
  2. `Current Session`: Active academic year (e.g. `2026-27`)
  3. `Total Students`: Active enrolled count per branch
  4. `Total Fees`: Gross invoiced tuition amount ($)
  5. `Total Paid Fees`: Actual realized revenue collected ($)
  6. `Total Balance Fees`: Net outstanding receivables due ($)

##### Table 2: Transport Fees Details (Fleet & Bus Services)
- Columns:
  1. `Branch`: Name of campus
  2. `Current Session`: Active academic year (`2026-27`)
  3. `Total Fees`: Gross transportation fees billed ($)
  4. `Total Paid Fees`: Actual bus fees collected ($)
  5. `Total Balance Fees`: Outstanding transport receivables due ($)

##### Table 3: Student Admission (Admissions Pipeline by Channel)
- Columns:
  1. `Branch`: Name of campus
  2. `Current Session`: Active academic year (`2026-27`)
  3. `Offline Admission`: Number of walk-in / in-person admissions enrolled
  4. `Online Admission`: Number of online applicant portal enrollments

##### Table 4: Library Details (Media & Resource Volume)
- Columns:
  1. `Branch`: Name of campus
  2. `Total Books`: Total media catalog holdings
  3. `Members`: Registered student & staff library cardholders
  4. `Book Issued`: Total active circulation loans

##### Table 5: Alumni Students (Graduate Directory)
- Columns:
  1. `Branch`: Name of campus
  2. `Current Session`: Active session
  3. `Total Alumni`: Graduated student records tracked

### Slug 02: Report (`/multi-branch/report`)
*Layout: 3-Column Categorical Report Directory Hub*

#### Hub Categories & 5 Specialized Multi-Branch Reports
- **Column 1 (Financial Collections & Operational Burn)**:
  1. `Daily Collection Report`: Cross-campus daily counter POS and online fee collection totals across all branches.
  2. `Expense Report`: Multi-branch operational expenditure and voucher audit.
- **Column 2 (Human Resources & Security Audit)**:
  3. `Payroll Report`: Staff salary disbursements, deductions, and tax withholdings across all campuses.
  4. `User Log Report`: Cross-branch administrative login history, IP addresses, timestamps, and role sessions.
- **Column 3 (Institutional Revenue)**:
  5. `Income Report`: Miscellaneous income and non-tuition revenue generated by each branch campus.

### Slug 03: Setting (`/multi-branch/setting`)
*Layout: Branch Federation & Instance URL Router Console*

#### 1. Header & Controls
- Title: `Setting`
- Top-Right Action Button: `+ Add New` (launches branch connection modal)
- Controls: Global Search Input, Page Size Dropdown (`100`), Export Toolbar (Copy, Excel, CSV, PDF, Print).

#### 2. Data Grid Columns
1. `Branch`: Official name of school branch / campus (e.g. `Branch Campus 1`, `Branch Campus 2`)
2. `URL`: Remote/Federated instance endpoint URL (e.g. `https://demo.smart-school.in/branch1/`, `https://demo.smart-school.in/branch2/`)
3. `Action`: Edit (Pencil), Delete (Cross)
- Pagination: `Showing 1 to N of N entries`.

#### 3. Modal Form: "Add New Branch" (Triggered by `+ Add New`)
- `Branch Name *`: Mandatory text input for branch name
- `Branch URL *`: Mandatory HTTPS endpoint URL for branch API routing
- Action: `Save` Button (persists branch endpoint in federation router).
